## 机器可验收标准

- 每个非空 Excel 列必须出现在本表；新增或删除列会让测试失败。
- 物品主表 68 行逐字段进入 `ITEM_DEFINITIONS`，剧情表额外物品以 `EXT_` 显式登记。
- 执行层按 `effect_key` 分派；关系生成、区域资源、禁区批次与稀有刷新读取参考参数。
- UI 展示公开人设、区域规则、物品效果；隐藏真相仅在解锁后展示。
