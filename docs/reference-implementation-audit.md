## 结论

## 本轮纠正

- 角色 HP、体力、饱食、禁区时间、热点和背包容量改为读取开局运行时表，不再由旧公式猜测。
- 物品按 `effect_key` 统一执行，消耗、持续时间、槽位、搜索权重、专属角色、全局稀有和刷新规则均保留；区域剧情表额外物品以 `EXT_` 明确登记。
- 关系网按配表生成 66 条无向边：4 条固定种子、4–6 条戏剧边、剩余陌生人边；限制每人额外戏剧边数量，隐藏总数 1–2，保留 `mutable / trigger_weight / source`，淘汰后冻结。
- 区域资源初始池改为 5，90 秒逐步恢复；缩圈按前/中/后期批量关闭 1–2 / 2 / 2–3 区，三块区域时一次压至一块并发放终局缓冲。
- 稀有物资修正为生命树枝 D1 夜两件、D2 夜两件；陨石碎片从 D1 夜起每次日夜切换一件、总计四件；其余三件按 D2/D3 昼夜生成。
- 隐藏任务使用各自行分数（50/40/45/45/60/100）并按全局表奖励干预点；评分、连击和评级从表中派生。
- 角色详情 UI 展示公开身份、年龄/性别观感、一句话、标签、口吻、简介、开局倾向、区域准入/环境/机制与逐件物品效果；隐藏真相只在真相解锁后出现。
