# AIdataosha 参考仓库最终落地审计

核对日期：2026-09-06  
参考版本：`HanataniTakahiro/AIdataosha@2a1d995`  
实现版本：本仓库 `p3.0-reference-complete`

## 可执行内容

- 12 名角色、13 个区域、17 条邻接关系、24 个区域剧情均进入配置与比赛循环。
- 63 个区域物品全部具备经济定义；5 个全局稀有物品按日夜阶段生成并可实际改变角色属性。
- 禁区按参考规则消耗角色的“禁区时间”，归零淘汰；普通生存阶段不再错误消耗该时间。
- 日夜饱食消耗、夜间视野/伏击、搜索/攻击/撤离体力成本、击杀补时均由服务端校验。
- 21 项参考主办方干预均可执行，包含区域修复、资源移除、双胜、隐藏资源、次数限制和冷却。
- 每局生成 4 条固定关系及 4–6 条随机关系，覆盖亲属、旧爱、宿敌、师徒、恋人和旧友。
- 6 个隐藏任务均可抽取并结算；普通隐藏任务奖励 50 热度与 3 干预点。
- 评分表、30 秒三连击、60 秒五连击、S/A/B/C 评级和真实热度历史已接入。
- 战略总览提供暂停/继续、关系网络、地图最近事件标记，以及公屏/剧情/对话三频道日志。

## 静态素材处理

参考地图、生命电池、事件图标和阈值控件作为运行时资产使用。带 UI、人物或文字的整页合成图，以及 Word/XMind/Markdown 策划资料用于视觉和规则验收，不重复嵌入运行时，避免烘焙文字覆盖实时数据。详细来源见 `docs/asset-provenance.md`。

## 自动验收

`data/battleRoyaleConfig.test.ts` 检查参考物品、干预、任务、评分和评级完整性；`convex/aiTown/battleRoyale.test.ts` 覆盖服务端比赛循环、剧情、关系、干预、回放与 AI 行动。
